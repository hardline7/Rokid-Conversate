# Conversate 사용법

현재 버전: `0.3.4-concepts` · 2026-11-17

## 준비

- 안경과 폰의 Rokid 앱을 연결한다. 기본 자막과 Rokid AI가 사용하는 계정·네트워크가 필요하다.
- 안경을 Wi-Fi에 연결한다. 관리 화면을 여는 폰/PC는 안경에 접근할 수 있는 같은 네트워크에 둔다.
- 안경에서 Conversate를 열면 관리 화면 주소와 6자리 PIN이 표시된다. 현재 주소는 `https://10.0.1.230:8443`이며 네트워크에 따라 달라질 수 있다.
- 브라우저에서 주소를 열고 PIN을 입력한다. 안경이 자체 생성한 인증서라 첫 접속 때 인증서 경고가 나온다. 표시된 안경 주소인지 확인하고 브라우저의 고급 메뉴에서 접속을 허용한다.

관리 화면의 **설정 → Rokid AI 연결 테스트**는 테스트용 질문과 자료로 실제 답변 생성을 확인한다. 이 테스트는 회의 기록이나 실제 Cue 목록에 추가되지 않는다. API 키를 입력하는 기능은 없다.

## 회의 전: 자료

관리 화면의 Prep Notes에서 제목과 내용을 입력하거나 TXT·MD·PDF를 올린다. UTF-8 텍스트 파일과 텍스트를 포함한 PDF를 지원한다. 스캔 PDF의 OCR은 포함하지 않는다. 파일은 8MB, PDF는 200페이지, 추출 내용은 자료당 60,000자까지다.

최대 100개를 저장할 수 있다. 회의에서 사용할 자료를 선택하면 시작할 때 해당 버전을 스냅샷으로 보관한다. 선택한 내용의 합은 100,000자 이하여야 한다. PDF 텍스트에는 `[p.1]`과 같은 페이지 표기가 붙는다. 업로드 원본 파일은 안경에 저장하지 않고 추출 텍스트만 저장한다.

## 회의 중: 안경 조작

| 상태/조작 | 동작 |
|---|---|
| 대기 중 탭 | 시작 확인 화면 |
| 시작 확인에서 탭 | 참석자에게 기록을 알렸음을 확인하고 시작 |
| 회의 중 탭 | 요약 → Cue → 자료 화면 순환 |
| 요약/Cue/자료에서 앞으로·뒤로 쓸기 | 이전·다음 요약, Cue 또는 자료 페이지 이동 |
| 두 번 탭, Cue 표시 중 | 현재 Cue 닫기 |
| 두 번 탭, Cue 없음 | 종료 확인 화면 |
| 종료 확인에서 탭 | 인식 종료 요청, 마지막 확정 발화 수신 후 회의 종료 |
| 확인 화면에서 두 번 탭 | 취소 |
| 일시정지 상태에서 탭 | 같은 회의 재개 |

관리 화면에서도 시작·일시정지·재개·종료를 할 수 있다. 시작은 안경의 Conversate 화면이 켜져 있을 때 가능하며, 참석자 알림 확인이 필요하다. 화면이 꺼지거나 다른 안경 화면으로 이동하면 인식을 일시정지한다. 다시 시작할 때 자동으로 몰래 재개하지 않는다.

10분 동안 인식된 발화가 없으면 회의를 자동 종료한다. 인식 결과가 없으면 폰의 Rokid 연결 상태를 확인한다. 안경과 폰의 연결 문제는 안경 내부 서비스의 Binder 연결 상태만으로 모두 판별할 수 없다.

## Cue와 요약

Rokid의 정식 AIUI `LanguageModel`을 실행하는 작은 도우미 위젯이 AI 요청을 처리한다. 회의 앱은 장치 내부의 인증된 루프백 연결로 작업을 전달한다. 도우미는 별도의 API 키를 요구하지 않으며 Rokid 계정 자격증명을 앱으로 복사하지 않는다.

- Answers·Bios: 선택한 자료의 원문 인용과 출처가 필요하다. 답변의 숫자는 인용문의 숫자 토큰과 일치해야 한다.
- Concepts·Suggestions: 최근 대화를 기준으로 필요할 때 생성한다.
- 한 번에 하나만 표시하며 8초 유지, 1초 페이드, 표시 사이 간격과 분당 4개 제한을 적용한다. 오래 대기한 Cue는 버린다.
- 같은 Concepts 제목은 한 회의에서 다시 표시하지 않는다.
- 90초 주기로 진행 중 요약을 요청하고, 종료 시 최종 리캡과 제목을 요청한다.
- 요약에는 실제 전사만 전달한다. 사전 자료를 회의에서 확정한 사실로 잘못 기록하지 않도록 Prep Notes와 이전 요약을 리캡의 증거에서 제외했다.

AI가 끊겨도 자막과 확정 발화 저장은 계속된다. 요약 상태가 실패/사용 불가이면 기록 화면에서 다시 요약할 수 있다. 모델 응답의 정확성과 지연은 보장하지 않으므로 중요한 결론은 전사와 대조한다.

## 회의 후: 기록

관리 화면의 기록에서 제목·내용을 검색하고 발화 묶음, Summary, Cue List, Transcription 탭을 볼 수 있다. Markdown으로 내보내거나 기록을 삭제할 수 있다. 검색과 내보내기는 외부 AI 호출 없이 작동한다. 안경이 켜져 있고 관리 서버에 접속할 수 있어야 한다.

새 회의 기록·자료·설정은 Android Keystore의 AES-GCM 키로 암호화한다. 확정 발화는 매번 동기 저장하며 중복 발화와 정정 결과를 구분한다. 중간 발화와 마이크 음성 파일은 회의 앱에서 저장하지 않는다. 이전 STT 진단 앱의 `files/transcripts` 자료는 변경하거나 삭제하지 않았다.

프로세스가 강제 종료되면 진행 중 회의는 다음 실행 때 중단 기록으로 복구하고, 진행 중으로 남은 요약은 재시도 가능한 상태로 바꾼다. 앱의 정리 코드가 실행되지 않는 강제 종료에서는 폰에서 자막을 끌 수 있어야 한다.

## AI 연결이 끊겼을 때

우선 안경 홈을 한 번 열었다가 Conversate로 돌아온다. 도우미 위젯이 호스트에 연결되고 몇 초 뒤 `Rokid AI 연결됨`이 표시되는지 확인한다. 설치를 복구해야 하면 PC에서 다음을 실행한다.

```powershell
.\tools\rokid-ai\Install-Helper.ps1
```

이 스크립트는 공식 AIX CLI로 개발자 모드를 켜고 이 프로젝트의 도우미만 설치·실행한다. 처음 설치할 때 준비했던 개발자 모드와 위젯 설정을 사용한다. `-Page`는 개발 진단용이며 회의 화면 위에 카드를 띄우므로 평소에는 사용하지 않는다.

Rokid의 [공식 LanguageModel 문서](https://open.rokid.com/aiui/api/ai/language-model?lang=en-US&version=0.19.0)를 바탕으로 구현했다. 모델 선택·계정 사용량·서버 보관 정책은 Rokid 쪽 설정에 따르며 이 앱이 제어하거나 무료·무제한임을 보장하지 않는다.
