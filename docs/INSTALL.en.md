# Install the APK and Rokid AI helper

[한국어](INSTALL.ko.md) · [English](INSTALL.en.md) · [Project](https://github.com/hardline7/Rokid-Conversate)

**You can install the release without building the Android app yourself.** There are two components: the Android APK connects to native captions, and the AI helper widget enables summaries and term explanations. Installing the APK alone does not install the widget.

## Downloads

Open the Assets section of the [v0.3.3 release](https://github.com/hardline7/Rokid-Conversate/releases/tag/v0.3.3).

| File | Purpose |
|---|---|
| `Rokid-Conversate-v0.3.3-Windows-Setup.zip` | Recommended. APK, helper sources, automatic installer and both language guides. |
| `Rokid-Conversate-v0.3.3.apk` | Standalone APK for manual installation. Does not install the AI widget by itself. |
| `SHA256SUMS.txt` | SHA-256 checksums for the APK and setup ZIP. |

Choose **Windows-Setup.zip**, rather than GitHub's automatically generated Source code ZIP, to get the APK and packaged installer together.

## Requirements

1. The device verified so far is **Rokid RG_glasses / Android 12 (API 32)**. Other models and firmware may behave differently.
2. Pair the glasses with the Rokid phone app and confirm native captions and Rokid AI are available.
3. Connect a USB data cable, enable USB debugging and approve your computer on the glasses.
4. Install [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools) and make `adb` available on PATH.
5. Install [Node.js](https://nodejs.org/) **20 or newer**, including npm, then open a new PowerShell window.

```powershell
adb devices -l
node --version
npm --version
```

The glasses should appear as `device`. If they show `unauthorized`, accept the debugging prompt on the glasses. Installing this release does not require Android Studio, the full Android SDK, JDK or a Gradle build.

## Recommended: install both components on Windows

1. **End any active meeting first.** Recognition cannot continue during an update.
2. **Fully extract** the Windows Setup ZIP to a folder. Do not run the script from inside the archive.
3. Open PowerShell in the extracted folder and run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Conversate.ps1
```

If multiple devices are connected, select the glasses explicitly:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Conversate.ps1 -Serial <device-id>
```

The installer:

- Checks the APK SHA-256, required tools and ADB device state.
- Refuses to update while the app still owns a recognition stream. End paused meetings normally too.
- Installs the APK with `adb install -r` and opens the glasses app.
- Prepares the pinned official `@yodaos-pkg/aix-cli@0.13.0`.
- Enables Rokid Developer Mode and installs and launches the project's AI helper widget.
- Briefly opens Home to attach the widget, then returns to Conversate.

Developer Mode stays enabled for the helper. No meeting is started by the installer. First-time npm downloads and Rokid helper registration require network connectivity.

## Check the glasses and companion

1. Wait for **Rokid AI connected** on the glasses. The wording follows their language.
2. Open the displayed `https://<glasses-ip>:8443` address from a phone or PC on the same network.
3. The device uses a self-signed certificate. Verify that the address belongs to your glasses before allowing that connection in your browser.
4. Enter the **current six-digit PIN on the glasses**. It changes after an app service restart.
5. Run the Rokid AI connection test in Settings. Synthetic test content is not added to meeting records.
6. Select notes and display options, inform participants, then start a meeting.

The default lens view shows speech-group summaries near the top. Swipe for previous/next summaries and tap to cycle Summary/Cue/Notes. Displayed live captions can be enabled or disabled independently.

## Manual APK installation

```powershell
adb install -r .\Rokid-Conversate-v0.3.3.apk
adb shell am start -W -n app.conversate.glass/.meeting.MeetingActivity
```

Then extract the Windows Setup ZIP and install just the helper from its folder:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Helper.ps1
# Multiple devices:
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Helper.ps1 -Serial <device-id>
```

Copying an `.aix` file alone is not enough. Launching the helper must supply a **device-specific local connection secret generated by this app**, which the installer handles. No Rokid account token or external AI API key needs to be entered.

You can also install the APK using ADB on macOS/Linux. The packaged automatic AI helper setup is a **Windows-verified PowerShell workflow**; equivalent setup on other operating systems has not been verified for this release.

## What “local + Rokid AI, no external AI API” means

**No separate third-party AI subscription, developer API key or application backend is required: the app uses local storage, Rokid's native STT and Rokid AI.** It does not directly call OpenAI, Claude or another third-party AI provider.

The companion connects to the glasses' HTTPS server. App-to-helper traffic uses authenticated `127.0.0.1` loopback. The helper invokes the Rokid host's official `LanguageModel` capability. Therefore **this is not a claim of zero API calls or fully offline AI**. Rokid's own phone/cloud connectivity, account limits and service policies can still apply. The app does not turn Rokid's service processing into on-device inference.

## Updates and signing

This preview uses a **development/debug-signed APK**. The helper installer relies on `adb run-as`, so it cannot simply be replaced by an ordinary non-debuggable release APK. The package contains neither private signing keys nor any existing device's runtime connection secret.

- Update a matching-signature build with `install -r` after ending meetings.
- A locally built APK may use a different signing key from the download. If Android reports `INSTALL_FAILED_UPDATE_INCOMPATIBLE`, stop and export existing records to Markdown first.
- Uninstalling can remove local records and the encryption key. The installer never uninstalls the app automatically to resolve a signature mismatch.
- There is no automatic update mechanism. Download the next setup package from Releases.

## Troubleshooting

| Symptom | What to do |
|---|---|
| `adb` not found | Add the Platform-Tools folder to PATH and open a new PowerShell window. |
| No device found | Check the USB data cable, debugging setting and authorization prompt. |
| Node.js error | Install Node.js 20+ with npm and reopen the terminal. |
| Active recognition warning | End the meeting and check that native Rokid captions have stopped on the phone. |
| AI waiting | Check pairing and Rokid AI availability; briefly open Home and return. If needed, rerun `Install-Helper.ps1` after ending the meeting. |
| English shown in another language | Korean/English are built in; other UI languages fall back to English while Rokid AI translation is prepared. |
| Companion connection fails | Check the current glasses address, network reachability and current PIN. |
