# Rokid Conversate v0.3.4 Preview — Contextual concept cues

## 한국어

대화 속 전문 용어를 Rokid AI가 설명합니다. 요약 생성과 독립적으로 새 확정 발화를 분석하고, 실제 언급된 용어만 검증해 요약 아래 잠시 표시합니다. AI Cue 탭의 점으로 새 Cue를 알리며, 한 번 탭해 상세 화면으로 이동하고 스와이프로 저장된 Cue를 봅니다.

- 개념별 세션 중복 제거, 알림 제한, 오래된 발화 건너뛰기
- Cue 자동 표시를 꺼도 목록 보관; AI Cue 자체를 끄면 분석 중지
- 발화 ID와 정확한 언급 구절 저장, 일반 모델 지식임을 표시
- Rokid 언어와 AI 사용, 별도 외부 AI API 키 없음

실제 Rokid AI의 합성 RAG 풀이가 검증을 통과했습니다. JVM 43개, 네이티브 한국어/영어 렌더 42종, 웹 회귀, lint/build를 확인했습니다. 실제 회의의 용어 검출률/오탐률은 아직 측정하지 않았습니다. G2의 공개된 사용 경험을 참고한 구현이며 내부 알고리즘·Pro Mode와 동등하다고 주장하지 않습니다.

기존 재부팅/강제 종료/OS 메모리 회수 후 AI 재연결 제한은 그대로입니다. 필요하면 앱을 열고 PC에서 AI 도우미 설치 스크립트를 다시 실행하세요.

## English

Rokid AI now analyzes new committed speech for specialized concepts independently of summaries. Validated explanations appear briefly below the summary and remain in AI Cue history. Single-tap opens the cue tab; swipe browses saved cues. Auto pop-up can be disabled separately from cue generation.

The app validates the actual term, utterance ID and triggering excerpt, deduplicates concepts, limits interruptions and labels definitions as general model knowledge. It uses Rokid AI and device language without adding an external AI API key.

Real-device synthetic RAG generation passed. Validation includes 43 JVM tests, 42 bilingual native renders, browser regressions and Android lint/build. Real meeting recall/false-positive rates remain unmeasured. This recreates a public interaction pattern, not G2's undisclosed algorithm or Pro Mode.

Existing AI reconnection limits after reboot, force-stop or OS process reclamation remain. Open the app and rerun the PC helper script if needed.
