# Rokid Conversate v0.3.2 Preview — Quieter idle operation

## 한국어

- 홈 화면의 상시 `CONVERSATE AI` 표시 제거
- AI 도우미의 매초 작업 조회를 최대 25초 대기 방식으로 변경, 작업 도착 시 즉시 응답
- 대기 heartbeat 제거, 회의가 없고 화면이 숨겨지면 서비스 점검 간격 30초
- 숨겨진 웹 탭의 상태 조회 생략, 늦게 생성된 AI 모델 세션 정리

연결된 안경에 설치하고 홈 화면과 실제 Rokid AI 요약·용어 생성을 확인했습니다. 55초 대기에서 작업 조회 2회·추가 heartbeat 0회·서비스 점검 1회를 확인했습니다. 상주 서비스는 남으며 배터리 소모율은 측정하지 않았습니다.

APK와 AI 도우미를 함께 업데이트하려면 Windows Setup ZIP을 사용하세요. APK만 설치하면 기존 도우미는 갱신되지 않습니다. [한국어 설치 안내](https://github.com/hardline7/Rokid-Conversate/blob/v0.3.2/docs/INSTALL.ko.md)

## English

Removed the persistent AI helper label and reduced idle work through 25-second long polling, task-only heartbeats and 30-second hidden idle service checks. Hidden web tabs skip state requests; late model creation is cleaned up.

Real-device checks confirmed the empty home widget, successful Rokid summary/term generation and two job requests, zero extra heartbeats and one service check over 55 idle seconds. The service remains resident; battery drain was not measured.

Use the Windows Setup ZIP to update both the APK and helper. APK-only installation does not update the helper. [English setup](https://github.com/hardline7/Rokid-Conversate/blob/v0.3.2/docs/INSTALL.en.md)

Validation: 37 JVM tests, 7 helper tests, Android lint/build, AIX check and companion web regression tests. Development/debug-signed preview; existing firmware compatibility and long-session limitations still apply.
