## English

This first downloadable APK preview brings speech-group summaries, terminology explanations, swipeable history, optional captions, preparation notes and post-meeting records to Rokid.

**No direct third-party AI API calls, developer API key or separately hosted app backend.** The app, encrypted records and companion run on the glasses; recognition and generation use Rokid's native STT and AI. It still invokes the Rokid host's `LanguageModel` and uses Rokid phone/services, so this is not a zero-API or fully offline AI claim.

### Download and install

- **Recommended:** Download `Rokid-Conversate-v0.3.0-Windows-Setup.zip` from Assets below for the APK, AI helper sources, installer and both language guides.
- Download `Rokid-Conversate-v0.3.0.apk` for manual APK installation. **The APK alone does not install the AI widget.**
- Verify the APK and ZIP against `SHA256SUMS.txt` if desired.

Install ADB and Node.js 20+/npm on Windows. Connect the glasses by USB and approve debugging. End meetings, fully extract the ZIP, open PowerShell in that folder and run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Conversate.ps1
```

The installer installs the APK and AI helper and enables Developer Mode. After the glasses show that AI is connected, open their displayed HTTPS address in a browser on the same network and enter the current PIN. The installer does not start a meeting.

[Detailed English APK and AI helper setup](https://github.com/hardline7/Rokid-Conversate/blob/v0.3.0/docs/INSTALL.en.md)

## Compatibility / 호환성과 배포 형태

- Verified hardware: **Rokid RG_glasses, Android 12 / API 32**. Other models and firmware are not comprehensively tested.
- This preview is a **development/debug-signed APK**, because the current local helper setup uses `adb run-as`. Private signing keys and runtime connection tokens are not included.
- Do not uninstall an existing differently signed build before exporting records. The installer never uninstalls automatically; read the signing/update section in the guide.
- Korean/English UI is built in. Other UI languages are generated and cached by Rokid AI, with English used while translation is pending. Existing transcripts retain their original text.
- Requires a paired Rokid phone and available Rokid STT/AI service. No claim of free, unlimited or offline Rokid service access is made.
- Native speech recognition uses a private integration that firmware updates can change. This is an independent project, not an official Rokid or Even Realities release.

## Validation / 검증

The Android project passes 29 JVM tests and lint/build. Real-device STT, lifecycle, AI summary display/storage and companion connectivity were verified during development. Installer tests exercise the APK/helper flow and refusal on active recognition, unauthorized ADB and checksum mismatch using mocks. The new installer has not been run as a destructive reinstall on a separate clean device. Full multi-model compatibility and long meeting/battery validation remain open.
